# 🧠 Recipe-Based Selectors

## The Secret to Reliable Tests

### How Flowstral Finds Elements:

| Strategy | What It Does |
|----------|--------------|
| **By Role & Text** | "Button with text Add to Cart" |
| **By Context** | "In the main content area" |
| **By Position** | "The 3rd matching element" |
| **By TestID** | "data-testid=submit-btn" |
| **Fallback Chain** | 10 strategies tried automatically |

### Benefits:
- ✅ **UI changes** → Test still finds element
- ✅ **Multiple matches** → Position-based disambiguation
- ✅ **Self-documenting** → Human-readable selectors
- ✅ **AI Optional** → Works without AI, AI enhances when enabled
