## 🚀 Usage

### Generate Training Data
```bash
# Default: 200 test cases + 200 automation examples
python scripts/generate_qa_synthetic_data.py

# Custom counts
python scripts/generate_qa_synthetic_data.py --test-cases 500 --automation 500
```

### Use New API Endpoints

**Task 1: Generate Test Plan**
```python
POST /ai/generate-test-plan
{
  "input": {
    "requirement_id": "REQ-123",
    "requirement_text": "As a user, I can...",
    "domain_tags": ["ecommerce"],
    "risk_level": "medium"
  }
}
```

**Task 2: Generate Tests + Code**
```python
POST /ai/generate-tests
{
  "input": {
    "requirement_id": "REQ-123",
    "requirement_text": "As a user, I can...",
    "target_frameworks": ["playwright", "pytest-api", "k6"],
    "test_plan": {...}  # Optional: from Task 1
  }
}
```
