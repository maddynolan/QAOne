2. Correlation: The Critical Difference

What is Correlation?

Dynamic values (session IDs, tokens) that change per session and must be extracted from responses and reused in subsequent requests.

LoadRunner (Manual - Hours of Work)

// Step 1: Identify dynamic values manually // Step 2: Add extraction BEFORE request web_reg_save_param("sessionId", "LB=session_id\":\"", "RB=\"", "Ord=1", LAST); // Step 3: Use in subsequent requests web_custom_request("GetData", "Headers=Auth: Bearer {sessionId}", LAST); // TIME: 2-8 hours per script // MAINTENANCE: Breaks when API changes

Flowstral (Automatic - Zero Effort)

// Auto-detected during recording { "correlations": [ { "name": "session_id", "type": "auto-detected", "pattern": "session_id\":\"([^\"]+)\"", "source": "response.body", "usedIn": [5, 7, 8, 12] } ] } // TIME: 0 seconds (automatic) // MAINTENANCE: Self-healing patterns
