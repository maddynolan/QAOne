Flowstral Pricing & Packaging Enterprise / High Tier

Sizing reference used for examples: ~3 min avg test duration, 50 parallel runs, video + HAR enabled by default.

Deployment options

  • Hybrid SaaS (recommended): Customer runs Worker Agent(s). We host UI/API/DB. Evidence can stay customer-side (BYO storage).
  • Full SaaS (dedicated): We host UI/API/DB + runner fleet + evidence storage.
  • Private SaaS in Customer Cloud: Runs in customer AWS/Azure account; we deploy/operate; customer pays infra.
  • Full On-Prem: Customer runs everything; we sell license + support packages.

Add-ons (simple knobs)

  • Extra concurrency: +$2,500 / month per +10 parallel runs (Full SaaS).
  • Extra evidence retention: +$400 / TB-month (SaaS storage) OR BYO storage (no storage charges).
  • SSO/SAML + Audit pack: +$1,000 / month (if not already included).
  • Premium support SLA: +$2,500–$5,000 / month depending on response time.
  • Managed customer workers: +$3,000 / month per 10 workers (operate in customer network).

Unit economics cheat-sheet (keep ROI high)

  • Default enterprise deployment: Hybrid SaaS + BYO evidence storage (customer S3/MinIO).
  • Separate pricing for (a) control plane features and (b) execution capacity (parallel runs).
  • Cap included evidence retention; charge for longer retention and large storage footprints.
  • Use evidence lifecycle policies (expire/move to cold storage) and 'video on failure' on lower tiers.
  • Offer BYO LLM key for cost-sensitive clients; keep managed LLM for premium tier.
  • Autoscale workers and use Reserved/Spot where policy allows (for Full SaaS).
