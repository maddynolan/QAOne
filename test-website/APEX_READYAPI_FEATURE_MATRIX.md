## 📝 Test Data Generation Guide

Apex automatically generates appropriate test data for each endpoint type:

### Authentication Endpoints

#### `/api/auth/register`
```json
{
  "email": "test_1234567890@example.com",
  "username": "testuser_1234567890",
  "password": "TestPassword123!",
  "full_name": "Test User"
}
```

#### `/api/auth/login`
```json
{
  "username": "testuser",
  "password": "TestUser@2024!Secure#Pass"
}
```

### Product Endpoints

#### `POST /api/products`
```json
{
  "name": "Test Product",
  "description": "Test Description",
  "price": 99.99,
  "category_id": 1,
  "stock": 10
}
```

#### `GET /api/products/{id}`
- Uses valid product IDs (1-100 for test website)

### Cart Endpoints

#### `POST /api/cart`
```json
{
  "product_id": 1,
  "quantity": 1
}
```

### Order Endpoints

#### `POST /api/orders`
```json
{
  "shipping_address": {
    "street": "123 Test St",
    "city": "Test City",
    "state": "TS",
    "zip": "12345",
    "country": "USA"
  },
  "payment_method": "credit_card"
}
```

### Custom Endpoint Defaults
- Generic endpoints get empty object `{}`
- Can be customized per endpoint

## 🎯 How to View Test Case Details

1. **Go to Execute Tab**
2. **Scroll to Test Cases Table**
3. **Click the 👁️ (Eye) icon** next to any test case name
4. **View Complete Details**:
   - Test Type & Priority
   - Expected Status Code
   - HTTP Method
   - Full Endpoint URL
   - Request Headers (JSON)
   - Request Body (JSON)
   - Query Parameters (JSON)
   - All Assertions
   - Expected Response Schema
   - Tags
   - OWASP Security Mapping (if applicable)
5. **Copy to Clipboard**: Click "Copy JSON" button
