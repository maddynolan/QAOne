## Detailed Description

### 🚀 The Fastest Way to Create Automated Tests

Flowstral Recorder captures your browser interactions and generates production-ready Playwright test scripts in milliseconds. Unlike cloud-based tools, everything runs locally in your browser for maximum speed and privacy.

### ✨ Key Features

**Smart Recording**
- One-click recording of clicks, inputs, and navigation
- Intelligent selector generation that survives UI changes
- Multi-tab and popup window support
- **HAR capture for load testing & API testing:** Optional Protocol Capture records HTTP/WebSocket as HAR; export for k6, JMeter, Postman, Insomnia

**Enterprise Application Support**
Built-in optimizations for 20+ enterprise platforms:
- Salesforce Lightning & Aura
- ServiceNow
- SAP Fiori & UI5
- Workday
- Oracle Cloud
- Microsoft Dynamics
- And many more...

**No-Code Test Building**
- Visual test builder with drag-and-drop steps
- Smart Fill: AI-generated test data
- Smart Assert: Intelligent verification suggestions
- Export to Playwright, Cypress, or manual test cases

**Local-First Architecture**
- All processing happens in your browser
- No data sent to external servers
- Works with localhost development servers
- Perfect for enterprise security requirements

### 🔒 Privacy First

- ✅ All data stays on your machine
- ✅ Optional cloud sync (self-hosted only)

## Privacy Practices (Chrome Store Dashboard)

### Single Purpose Description
"Record browser interactions and generate automated test scripts for web application testing."

### Permission Justifications

**activeTab**
"Required to access the current page's DOM when the user starts a recording session. Only activates on user action."

**storage**
"Stores recorded test sessions and user preferences locally on the device."

**tabs**
"Enables multi-tab recording for applications that open new windows or popups during user workflows."

**scripting**
"Injects the recording script into web pages when the user initiates a recording session."

**downloads**
"Allows users to export generated test scripts as downloadable files."

**sidePanel**
"Displays the recording control panel and test builder interface."

**webRequest**
"Optional feature: Captures network requests for performance testing analysis. Disabled by default."

**Host Permissions (<all_urls>)**
"QA testing requires access to any domain the user wants to test, including localhost development servers and enterprise applications on various subdomains. The extension only activates when the user explicitly starts a recording session."

### Data Usage
- ☐ I certify this extension does not collect user data
- ☑ This extension collects user data (see below)

**Data collected:**
- Website content: DOM element information for generating test selectors
- User activity: Click and input actions during recording sessions

**Data handling:**
- ☑ Data is processed entirely on the user's device
- ☑ Data is not sold to third parties
- ☑ Data is not used for purposes unrelated to the extension's core functionality

### Remote Code
"This extension does NOT execute any remote code. All functionality is bundled within the extension package. API calls to user-configured servers only send/receive JSON data, never executable code."
